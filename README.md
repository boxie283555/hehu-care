# 禾护 · 过敏儿童生长与营养管理

可在本机运行的首版业务原型。以电子问卷为入口，连接监护人、医护评估、管理计划与动态随访。

## 本机启动

Windows 可双击 `start-windows.cmd`，自动检测并安装 Python；无需提前手动安装。macOS / Linux 命令行运行需要 Python 3.9 或以上。应用无需安装后端依赖。

```sh
python3 launcher.py
```

也可双击 `启动禾护.command`。访问 http://127.0.0.1:8765 。启动器会复用已经运行的本应用服务；后台日志在 `data/server.log`。

前台运行（按 Ctrl+C 停止）：

```sh
python3 server.py
```

本应用默认仅监听 `127.0.0.1`，不向其他设备开放。端口可通过 `PORT` 环境变量修改，数据库路径可通过 `CARE_DB` 修改。启动器也支持 `HOST` / `PORT` 环境变量，或 `--host` / `--port` 参数。

## Windows 启动（推荐）

**双击 `start-windows.cmd`，无需预先安装 Python。** 启动脚本先寻找已有的 Python 3.9+（包括Python启动器、PATH和注册表）；找不到时从 Python 官网选择最新稳定的3.13补丁版本，校验有效的 Python Software Foundation 数字签名后，静默安装到当前用户的 `%LOCALAPPDATA%\Hehu\Python313`。默认不需要管理员权限，不修改系统PATH，不安装pip或额外服务；后续启动复用现有环境，不重复下载。首次自动安装需要联网，并受Windows安装策略约束。

脚本从项目目录启动服务，启动失败时保留报错窗口。服务运行期间不要关闭此窗口，在浏览器打开 http://127.0.0.1:8765 。该入口不依赖 VS Code 调试器。

如 Python 不在 PATH，可在 PowerShell 中指定解释器：

```powershell
$env:PYTHON_EXE = "C:\Program Files\Python311\python.exe"
.\start-windows.cmd
```

需要后台运行时使用 `py -3 launcher.py`。启动器在 Windows 禁用 debugpy 子进程自动注入，并尝试脱离调试作业；受 Windows 作业策略限制时会提示改用 CMD 入口。推荐从独立 PowerShell 启动，而不是依赖调试会话。

局域网访问：

```powershell
$env:HOST = "0.0.0.0"
.\start-windows.cmd
```

其他设备访问 `http://Windows电脑实际IP:8765`；必要时放行 Windows 防火墙的对应端口。默认仍只允许本机访问。后台启动日志为 `data/server.log`；CMD 入口的日志直接显示在窗口中。

## 家长扫码填写指定问卷

医院端登录后进入 **「问卷二维码」**（电子问卷页也有入口）：

1. 选择首次综合评估、生长与营养随访或过敏症状随访。
2. 确认手机可访问的系统地址，点击「生成二维码」。
3. 下载 PNG 发给家长，或点击「打印二维码」打印诊室海报。
4. 家长扫码 → 手机验证码登录 → 选择或建立患儿档案 → 直接填写该问卷 → 提交成功。

二维码仅包含问卷类型，不包含患儿ID、身份信息或登录凭据。所有患儿读取与提交仍校验账号归属。登录、刷新及建档期间保留问卷入口；草稿可在选定患儿后继续填写。当前仍为开发验证码，没有真实发送短信。

### 同一 Wi-Fi 下体验

先停止旧的本机监听服务，使用以下任一方式重新启动：

- Windows：双击 **`start-lan-windows.cmd`**，保持窗口打开。
- macOS：双击 **`启动禾护-局域网.command`**。
- 命令行：`python launcher.py --lan`（macOS通常为 `python3`）。

系统会检测候选局域网IP，医院端可修改地址。先在手机浏览器验证地址能打开，再生成二维码；手机与电脑需处于可互访的同一局域网。多网卡/VPN、访客Wi-Fi隔离及Windows防火墙均可能影响连接。Windows必要时允许对应端口入站。局域网IP变化后，需要重新生成并替换二维码。

仅监听127.0.0.1时，启动器不会把已有服务误认为局域网服务；生成局域网二维码时也会要求切换启动方式。

### 后续 HTTPS 地址

正式部署时可以设置 `PUBLIC_BASE_URL=https://care.example.com`，作为二维码默认地址和明确允许的请求来源；配置后Cookie附加Secure。需要自行完成域名、证书、HTTPS反向代理与正式短信接入。该变量本身不会发布互联网服务或签发证书。当前实现要求站点部署在域名根路径，不支持子路径部署。

局域网二维码在浏览器本地生成，未调用第三方二维码服务；二维码生成库为 MIT 许可的 qrcode-generator 1.4.4，已随源码提供。

## 首版功能

- 监护人登录与多患儿建档，服务端校验档案归属；演示医护可查看本机全部患儿。
- 首次综合评估、生长营养随访、过敏症状随访问卷；草稿恢复、提交后保留记录、固定 v1.0 版本标识。24月龄以下显示喂养补充项。
- 身高/身长、体重、测量日期和来源记录，按真实时间绘制趋势；日期、数值范围及重复测量校验。
- 医护人工评估、关注级别、个体化计划及计划历史。保存计划生成随访问卷任务。
- 关联任务提交问卷后完成任务，或医护记录核实结果；显示逾期情况。
- 家长报告“有所加重”进入待复核事项；医护记录处理结果、处理人和关闭状态。
- 家长留言、医护回复。异步留言，每次打开或刷新页面获取最新数据；未实现实时推送。
- 医护导出不含姓名/手机号的生长记录 CSV，查看最近150条访问与操作审计。
- 适配桌面和手机宽度；数据保存在 SQLite，重启保留。

## 推荐体验流程

1. 家长登录，查看示例档案或新建演示患儿。
2. 填写问卷、保存草稿再提交；录入生长记录。
3. 退出后以医护登录，选择该患儿，查看问卷与曲线。
4. 新建综合评估、制定计划和下次随访日期。
5. 处理关注事项并回复家长留言。
6. 再以家长登录，从随访任务进入问卷并提交，确认任务完成。

## 数据与架构

- 前端：原生 JavaScript / CSS，静态资源本地提供，无外部CDN依赖。
- 后端：Python 标准库 HTTP 服务；SQLite 参数化查询与事务。
- 安全基础：HttpOnly、SameSite=Strict 会话 Cookie，服务端角色/归属控制，同源JSON写请求，密码PBKDF2哈希，验证码哈希存储，审计日志。
- 业务实体：用户、会话、监护归属、患儿、测量、问卷、评估、计划、随访任务、关注事项、留言、审计。
- 本版以快速本地运行和验证流程为目标，采用轻量实现；正式建设时可迁移至方案中的 Vue / Spring Boot / PostgreSQL。

`data/care.sqlite3` 为本地业务数据库，已加入 Git 忽略。**数据库文件本身尚未加密，请仅使用演示信息。** 不要在运行中单独复制主数据库文件充当完整备份（WAL模式可能存在未合并数据）；应停机后备份整个data目录，或使用SQLite备份API。

## 尚待医院确认与后续实现

- 临床量表、使用授权、参考标准、评分与风险阈值；当前不提供百分位/Z分数、自动营养诊断或处方。
- 后台问卷编辑/发布、更多条件跳题、按版本统计；目前问卷为固定版本，前端提供三种场景入口。
- 真实短信、定时外发提醒、发送失败重试与自动升级；当前仅有应用内任务/逾期提示。
- HIS、患者主索引、实名与监护关系核验、多名监护人共享授权。
- 科室/医生分管权限、正式账号管理、附件上传、临床评估签署及生产级数据加密。
- 受控生产部署、HTTPS、备份恢复、监管合规评审。当前标准库服务器仅用于本机原型。

急性严重症状应及时就医，不能等待线上问卷或留言处理。系统不自动建议停药或重新引入回避食物。


API测试使用临时数据库，覆盖跨家长隔离、医护权限、验证码防重放/限流、数据校验、问卷草稿与提交、计划、随访完成、复核、留言和导出审计。

```sh

```

浏览器依赖默认使用本机Codex bundled runtime；其他机器可通过 `PLAYWRIGHT_PATH` 指定Playwright模块路径。测试不写入正式演示数据库。

二维码及扫码端到端测试（需要 Node.js、本机 Chrome）：

```sh

```

应用运行本身不依赖 Node.js。扫码测试独立解码下载的PNG，验证二维码内容、打印版式、真实局域网地址访问、新家长建档、草稿恢复、多患儿选择与问卷提交。

### Windows 自动安装说明

- `start-windows.cmd` 和 `start-lan-windows.cmd` 均会自动准备Python。
- 已有Python版本不满足3.9+时，会另装本系统的用户级运行环境，不卸载原有Python。
- 显式配置了无效的 `PYTHON_EXE` 时会提示纠正，不会悄悄覆盖管理员的选择。
- 下载或签名校验失败时停止执行，窗口保留错误，修复网络后重新双击即可。
- `PUBLIC_BASE_URL`、`HOST` 和 `PORT` 环境变量会传递给服务；自动安装Python不等于配置公网域名、HTTPS或短信。
- 自动安装仅针对Windows入口；macOS/Linux尚未包含系统级安装器。
- 如需只准备环境、不启动服务：`powershell -NoProfile -ExecutionPolicy Bypass -File .\bootstrap-windows.ps1 -InstallOnly`。
